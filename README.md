# コトサーチ（パソコン版）

ご自身のパソコンで動く、SEO 記事の作成と内部リンク設計のツール「コトサーチ」の配布の置き場です。
ここには、設置と更新を行う「管理役」と、新しい版のお知らせだけを置いています（ソースコードはありません）。

## ダウンロード

右の「Releases」の一番新しい版から：

- **kotosearch-manager.mcpb**：Claude（デスクトップアプリ）用。ダブルクリックで入ります
- **kotosearch-manager.zip**：Codex・コマンドで使う人用

## 始め方

1. Docker Desktop を入れて起動する
2. 管理役を入れて、Claude に「コトサーチがこのパソコンで動くか確かめて」と伝える（無料の動作チェック）
3. 「コトサーチを設置して」と伝える → ブラウザで開いた画面に、購入のメールのライセンスを貼り付ける

くわしい手順は、購入のメールにある「始め方」のページをご覧ください。

ご利用には、購入時にお送りするライセンスが必要です。
